- Web-palvelimen asennus ja testaus. Opiskelija asensi Apachen palvelimelle, teki määrityksiä palomuuriin ja asensi uusimmat paketit sekä päivitykset. Lopuksi hän käynnisti koneen uudelleen.

### Artikkeli 2.

**Partanen 2025: Harjoitus 5: Nimekäs: a) Nimi**

Tässä artikkelissa opiskelija hankki domain-nimen tehtävää varten. Domainin tulee osoittaa omaan virtuaalipalvelimeen.

- Domainin osto. Opiskelija valitsi palveluntarjoajan ja selvitti palvelun hinnan.

- DNS-asetuksien säätäminen. Opiskelija poisti CNAME-tietueen ja asetti kaksi A Record-tietuetta tilalle. TTL-asetukseksi hän valitsi 5 minuuttia, jotta muutokset näkyisivät nopeammin.

- Testaus. Lopuksi opiskelija testasi verkkosivua ja se toimi juuri niinkuin pitikin. Verkkosivulle pääsee ilmankin www-etuliitettä, koska hän sääti DNS-asetuksia edellisessä vaiheessa.

## f) Vaihtoehtotehtävä

### Käyttäjä dimi on jo sudo-ryhmässä, koska jätin root-salasanan tyhjäksi asennuksen aikana.

![alt text](screenshots/f1.png)

### Seuraavaksi asennan ufw.
```
sudo apt-get install ufw -y
```

![alt text](screenshots/f2.png)

### Sallin SSH-portin, otin palomuurin käyttöön ja tarkistin sen tilan. Järjestys on tärkeä, koska muuten etäyhteydellä voi lukita itsensä ulos koneelta.
```
sudo ufw allow 22/tcp
sudo ufw enable
sudo ufw status verbose
```
![alt text](screenshots/f3.png)

### Seuraavaksi asensin Apache-weppipalvelimen.
```
sudo apt-get install apache2 -y
```
![alt text](screenshots/f4.png)

### Sallin HTTP-portin palomuurissa ja tarkistin, että muutos on voimassa.
```
sudo ufw allow 80/tcp
sudo ufw status verbose
```
![alt text](screenshots/f5.png)

### Vaihdoin oletusweppisivun ja yritin tarkistaa sen curl-komennolla. Tarkistus epäonnistui, koska curlia ei ollut vielä asennettu, joten asensin sen ja tarkistin sivun uudelleen.
```
echo "test page" | sudo tee /var/www/html/index.html
sudo apt install curl -y
curl localhost
```
![alt text](screenshots/f6.png)

### Lisäksi tarkistin sivun nettiselaimella.

![alt text](screenshots/f7.png)

### Seuraavaksi simuloin nimipalvelua lisäämällä hosts-tiedostoon uuden rivin ja tallentamalla muutokset.
```
sudoedit /etc/hosts
```
![alt text](screenshots/f8.png)

![alt text](screenshots/f9.png)

### Lopuksi tarkistin, että nimi toimii sekä komentorivillä että nettiselaimella.
```
getent hosts sivu.test
curl sivu.test
```
![alt text](screenshots/f10.png)
